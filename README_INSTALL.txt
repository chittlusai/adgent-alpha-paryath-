WHY DOES WINDOWS SHOW "UNKNOWN PUBLISHER" OR "RISK"?
------------------------------------------------------------------------
When you download any newly released application from the internet,
Windows Defender SmartScreen attaches a download quarantine tag (Mark of the Web)
and displays:
  "Windows protected your PC"
  "Microsoft Defender SmartScreen prevented an unrecognized app from starting."
  "Publisher: Unknown publisher"

This is Windows' standard default message for any newly compiled program
that has not yet accumulated thousands of downloads in Microsoft's cloud.
IT IS NOT A VIRUS, FRAUD, OR HARMFUL APPLICATION.
